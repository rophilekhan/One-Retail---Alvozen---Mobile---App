Pharmacy App
OneRetail by Alvozen

•	Core Features (App):
o	Pharmacy Profile
o	Home Page - Dashboard + Analytics + Prescription Scanning + Dispense Confirmation
o	Trade Schemes
o	Distributor-Connect
o	Engage
o	Pharmacy Impact Index + Wallet
o	Staff Profile Creator + Hierarchy Settings
o	Settings

•	Core Features – Pharmacy Profile:
o	Sign-up / User set-up:
	Phone Number + Email Address Input – OTP Verification
	Create Username / Password
	DSL Number 
	DSL Expiry Date
	DSL Picture
	Further License Number– 1
	Further License Number - 1 Expiry Date
	Further License Number – 1 Picture
	Further License Number– 2
	Further License Number – 2 Expiry Date
	Further License Number – 2 picture
	Pharmacy Address + Location Pin
	Pharmacy Façade Photo
o	Pharmacy Impact Index: Pharmacy sees their own composite score and what drives it

•	Core Features – Home Page:
o	Analytics:
	Prescriptions per day
	Top Brands in the Territory along with their share of Sales
	Territory Benchmarking
	Note: Alvozen Admin should specify a Default Territory and each Pharmacy would be under a certain Territory
o	Prescription Scanning:
	This is to be used by those Pharmacies, which do not have any System in place. Therefore, the scanning happens through the phone. 
	Even those Pharmacies, where the System is there but not integrated with Alvozen can use this as well.
	When Prescription is scanned, the user can:
	If Prescription Brand is not available, view Availability of the Prescription Brands at nearby Pharmacies:
•	Pharmacy Name - Distance (km) – If ‘SKU Visibility’ is turned On from Settings section.
	View Alternate Brands of the same Generic as the brand in the Prescription
•	The MRP / TP of all the Alternate Brands
	When Prescription has a Generic Name (Generic id should be in the QR Code):
•	View all the Brands which are mapped with that Generic:
o	Brand Name – TP – MRP – Availability Status – Active Scheme
o	Dispense Confirmation:
	If the system not integrated, the user would be prompted to enter the quantity dispensed against each SKU.
	If a Brand is substituted, the user would be asked to search and select the substitute Brand and the quantity that was dispensed of that Brand. 
•	The Substitute options would be provided on the basis of:
o	Generic
o	Therapeutic Segment


•	Core Features – Pharmacy Impact Index + Wallet:
o	Tier Status:
	General / General Trade
	Established
	Key Account
	Flagship
o	The tiers would be based on Pharmacy Impact Index (PII) points.
o	PII Points system: Platform points earned across all activities:
	For Digital Prescription interaction (Scan the Prescription QR Code)
	For Data sharing with Pharma Industry
	For Digital Pharma Engagement activities
o	Earnings dashboard (Financial Incentive System): Real-time view of total earnings, pending amounts and payment history earned across all activities:
	For Digital Prescription interaction (Scan the Prescription QR Code)
	For Data sharing with Pharma Industry
	For Digital Pharma Engagement activities
o	Redemption:
	Cashout via EasyPaisa / bank: Withdraw earnings to EasyPaisa, JazzCash or bank account with tax documentation

•	Core Features – Staff Profile Creator:	
o	Username 
o	Password
o	Allowed Access:
	Scan QR through device
	Scan QR through Plug-in
	PO Initiator
	PO Approver
	Expiry Initiator
	Expiry Approver
	Upload Closing Data (if not integrated Systems)
o	Note: The Pharmacy admin can create multiple Staff Profiles. Also can deactivate any profile and can change the Password for any of the Profiles.

•	Core Features – Settings:
o	SKU visibility for other Pharmacies:
	If a Pharmacy turns it off:
•	Other Pharmacies cannot view the SKU-Level data of this Pharmacy through their Platform. 
•	The concerned Pharmacy also would not be able to view the SKU-Level data of other Pharmacies through the Platform.
o	Pharmacy controls who can contact them and what data is visible to pharma
